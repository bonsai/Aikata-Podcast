# MVP コスト・工数見積もり

> 目的: MVP（T01〜T15）の実装工数と、リリース後の1エピソードあたり変動費を概算し、スコープと投資判断の材料とする。
> 前提: 日本語3分番組、AIホスト＋人間話者、Cloudflare-first構成。
> 注意: 単価はPOC確定前の仮定。確定後に本ファイルを更新すること。

## 1. 実装工数見積もり（T01〜T15）

工数は「実装＋単体テスト＋軽い手動確認＋関連文書更新」を含む目安。保守的に見積もっている。

| ID | タスク | 内容 | 見積工数 | 累計 |
|---|---|---:|---:|---:|
| T01 | 最小アプリの骨格 | TypeScript + React + Hono + Wrangler 構成、型チェック・テストコマンド | 4〜6h | 4〜6h |
| T02 | 画面の基本導線 | エピソード一覧・作成・詳細、空状態・読み込み中・エラー | 6〜8h | 10〜14h |
| T03 | D1 CRUD | shows/episodes テーブル、入力検証、所有権境界 | 6〜8h | 16〜22h |
| T04 | 台本エディター | 3分構成テンプレート、話者・発話順・本文編集、推定尺表示 | 10〜14h | 26〜36h |
| T05 | 台本生成サービス | LLMアダプター、構造化出力検証、失敗時フォールバック | 10〜14h | 36〜50h |
| T06 | ブラウザマイク録音 | 許可・録音・再生・やり直し、R2保存、asset記録 | 12〜16h | 48〜66h |
| T07 | AIホスト音声生成 | TTSアダプター、承認済み台詞生成、R2保存、メタデータ | 8〜12h | 56〜78h |
| T08 | 音声素材一覧・プレビュー | 人間/AI区別表示、再生・差し替え・削除整合 | 6〜8h | 62〜86h |
| T09 | 最小トラック編集 | 順序変更、トリム、音量、編集JSON保存、プレビュー | 14〜18h | 76〜104h |
| T10 | ミックスとダウンロード | ブラウザ/サーバー処理、MP3/WAVフォールバック、状態表示 | 14〜18h | 90〜122h |
| T11 | 書き出しの堅牢性 | 空トラック・破損素材・長時間処理、重複実行防止、再試行 | 6〜8h | 96〜130h |
| T12 | コンプライアンス確認 | 権利・出典・同意チェックリスト、重大警告 | 4〜6h | 100〜136h |
| T13 | セキュリティレビュー | 秘密情報漏洩防止、認可、R2保護、入力検証、削除 | 6〜8h | 106〜144h |
| T14 | E2E・受入テスト | 主要フローと失敗系、Windows Chrome/Edge | 10〜14h | 116〜158h |
| T15 | Cloudflareデプロイ | D1/R2/Secrets設定、マイグレーション手順、URL確認 | 6〜8h | **122〜166h** |

### 工数の解釈
- フルタイム換算: 122h ÷ 8h ≈ 15営業日、166h ÷ 8h ≈ 21営業日
- 週3日換算: 約5〜7週間
- 週末・夜間作業: 2〜3ヶ月程度

### スコープ圧縮候補（時間がない場合）
時間がない場合は以下を優先して縦切りを完成させ、残りは後回しにする。

| 優先 | タスク | 理由 |
|---|---|---|
| Must | T01, T02, T03 | 骨格・画面・永続化なしでは何も動かない |
| Must | T04（簡易版） | 手入力台本だけでも縦切りを完成できる |
| Must | T06 | 人間録音はMVPの核心体験 |
| MUST | T09, T10（最小版） | トラック編集を省略し、単純な結合・ダウンロードに縮小可能 |
| Should | T05 | LLM生成は手入力の代替。手入力が動けば後回し可能 |
| Should | T07 | TTSも手入力台本＋録音のみなら後回し可能 |
| Could | T08 | 一覧は最小でも可。削除整合だけはT06/T07とセット |
| Could | T11, T12, T13, T14, T15 | セキュリティ・品質は重要だが、縦切り完成後に回す |

### 最小縦切り案（工数目安 50〜70h）
1. T01 + T02 + T03: 16〜22h
2. T04 簡易台本保存: 6〜8h
3. T06 人間録音＋R2保存: 12〜16h
4. T10 単純ダウンロード（1トラック書き出し）: 8〜12h
5. T13 最小認可チェック: 4h
6. 手動テスト・デプロイ準備: 4〜8h

合計: **50〜70h** で「テーマ→台本→録音→ダウンロード」の縦切りを完成できる。

## 2. 運用変動費（1エピソードあたり）

Cloudflare の無料枠を前提に、1エピソード（3分）あたりの超過コストを試算。

### 前提条件
- LLM: 台本生成に 2回呼び出し、入力約 4,000 tokens、出力約 2,000 tokens
- TTS: AIホスト台詞 約 300文字（日本語）、1回生成
- 保存: 人間録音 WAV 約 5MB + TTS音声 約 2MB + 書き出しMP3 約 3MB = 約 10MB
- ダウンロード: 10MB/回、月間 100エピソード書き出し
- APIリクエスト: 1エピソードあたり約 50〜100リクエスト

### 仮単価（POCで確定させること）
| 項目 | 仮単価 | 備考 |
|---|---|---|
| LLM input | $0.00675 / 1K tokens | Workers AI llama-3.1-8b 想定（要確認） |
| LLM output | $0.00675 / 1K tokens | Workers AI llama-3.1-8b 想定（要確認） |
| TTS | $0.0015 / 1K文字 | 日本語TTSの目安（要確認） |
| R2 ストレージ | $0.015 / GB・月 | 10MB × 100本 = 1GB/月 |
| R2  egress | $0.09 / GB | 無料枠 10GB/月を超えた場合 |
| Workers リクエスト | $0.50 / 100万リクエスト | 無料枠 10万/日を超えた場合 |

### 試算
| 項目 | 計算 | 1エピソードコスト |
|---|---|---:|
| LLM input | 4K tokens × $0.00675/1K | $0.027 |
| LLM output | 2K tokens × $0.00675/1K | $0.0135 |
| TTS | 0.3K文字 × $0.0015/1K | $0.00045 |
| R2 ストレージ | 10MB × $0.015/GB（月次換算） | ~$0.00015 |
| R2 egress | 10MB × $0.09/GB（無料枠超過時） | ~$0.0009 |
| Workers | 100リクエスト分（無料枠内） | ~$0 |
| **合計** | | **約 $0.04〜0.05 / エピソード** |

### 月間100エピソード運用時
- LLM: $4.05
- TTS: $0.045
- R2 ストレージ: ~$0.015
- R2 egress: ~$0.09（無料枠10GB内に収まる）
- Workers: 無料枠内
- **月間合計: 約 $4.10〜$5.00**

### 注意点
- **TTSの品質と価格が最も不確定**: POC-02 で必ず確認。
- **ミックス処理をWorkers上でffmpeg.wasm等で行う場合**: CPU時間・メモリ制限に引っかかる可能性あり。ブラウザ内処理ならサーバー原価は下がるが、互換性が課題。
- **無料枠を超えるまで実質コストはほぼゼロ**。初期検証ではコストより「制限・レイテンシ・失敗率」が重要。

## 3. 結論・アクション

1. **工数面**: MVPフルスコープは約 122〜166h。時間がないなら、**最小縦切り案（50〜70h）**で「テーマ→台本（手入力可）→録音→ダウンロード」を先に完成させる。
2. **コスト面**: 1エピソードあたりの変動費は約 $0.04〜0.05 と非常に小さい。原価よりも**開発工数・POCリスク**が大きな投資対象。
3. **POC優先**: TTS単価・品質・Workers AIの制限は確定前に見積もりを再計算すること。
