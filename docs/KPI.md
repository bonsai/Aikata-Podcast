# KPI — 指標と計測計画

## 方針
登録者数や生成回数だけでなく、完成音声の書き出しと再制作を評価する。以下は**検証開始時の仮目標**であり、実績値ではない。

## North Star Metric
**週次完成エピソード数:** 1週間にユーザーが正常に書き出したエピソード数。内部テストは除外する。

## KPI候補

| 指標 | 定義 | 初期仮目標 |
|---|---|---:|
| Activation | 初回利用から7日以内に初回エクスポートした新規ユーザー割合 | 40%以上 |
| Time to First Export | 制作開始から初回書き出しまでの中央値 | 15分以内 |
| Export Success Rate | 成功した書き出し / 書き出し試行 | 95%以上 |
| Script Completion | 台本保存後、収録工程へ進んだエピソード割合 | 60%以上 |
| 4-week Repeat | 初回書き出し後4週間以内に再書き出ししたユーザー割合 | 25%以上 |
| TTS Success | 成功したTTS要求 / 全TTS要求 | 95%以上 |
| Usefulness | 完成後アンケートで「役に立った」以上の割合 | 70%以上 |
| Cost per Export | 変動費 / 成功した書き出し数 | 実測後に上限設定 |

## ファネル
訪問 → 制作開始 → エピソード作成 → 台本保存 → 録音 → TTS（任意）→ プレビュー → 書き出し成功 → 2本目の制作。工程別到達率を見て離脱点を改善する。

## 最小イベント
episode_created、script_saved、recording_started、recording_completed、tts_requested、tts_succeeded、tts_failed、preview_played、export_requested、export_succeeded、export_failed、asset_deleted、episode_repeated。

イベントに音声本文、台本全文、個人情報を含めない。計測導入前にプライバシー説明と同意要件を確認する。

## 運用品質
APIエラー率、TTS失敗率、書き出し失敗率、処理時間中央値/p95、1本あたり保存容量・費用、削除成功率、不正アクセス拒否テストを記録する。

## 計測ルール
- イベントの発火条件、重複排除、タイムゾーンを定義する。
- 内部テスト・ボット・再試行を区別する。
- 少数サンプルでは割合だけでなく件数も示す。
- 未計測の項目を達成済みとして報告しない。
- 週次でファネル・障害・コスト、月次で継続利用・支払意思を見直す。
