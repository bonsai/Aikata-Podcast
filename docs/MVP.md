# MVP — Minimum Viable Product

## 目的
一人のクリエイターが、テーマから約3分の対話音声を制作し、完成ファイルをダウンロードできることを最短で検証する。

## 中心体験
テーマ入力 → AIが構成・質問案を作る → 人間が台本を確認 → 人間が録音 → AIホスト音声を生成 → プレビュー・簡易編集 → 書き出し。
実装は人間の録音とダウンロードの縦切りを先に完成させ、TTSを次に加える。

## 必須機能
- 番組・エピソードの作成、一覧、保存、再読込
- テーマ、対象リスナー、トーンの入力
- 3分構成と話者別台本の生成または手入力、編集・保存
- ブラウザマイク録音、再生、やり直し
- AIホストTTSと人間音声の素材・トラック管理
- 最小限の順序・開始終了・音量調整
- プレビューと対応形式のダウンロード
- エラー表示、素材削除、基本的な権限チェック

## 今回は作らない
自動配信、RSS、配信分析、リアルタイム全二重会話、高度なノイズ除去・DAW、チーム編集、決済、独自の声の学習、ネイティブアプリ。

## 最小技術構成
TypeScript + React、Cloudflare Workers + Hono、D1、非公開R2、MediaRecorder / Web Audio API、LLM/TTSアダプター。デプロイ先と音声処理方式はPOC結果で見直す。

## 完了条件
- 新規エピソードから音声ダウンロードまで主要フローを再現できる。
- 保存した台本・素材を後から開ける。
- マイク拒否、TTS失敗、録音失敗、書き出し失敗が判別できる。
- 原音声を編集で上書きしない。
- 他ユーザーのデータへアクセスできず、秘密鍵がクライアントに露出しない。
- 主要フローのテストとCloudflareデプロイを確認する。
- KPI計測方針とプライバシー説明がある。

## リリース後に学ぶこと
初回書き出し時間、工程別離脱、AIホスト利用率、2回目の制作率、時間のかかる工程、支払意思。
