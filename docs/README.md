## 基本方針
- 製品の焦点は、AIホストと人間の声で約3分の対話番組を制作し、音声ファイルとして持ち出せること。
- 配信プラットフォームを作るのではなく、企画・台本・収録・最小編集・書き出しを一つの流れにまとめる。
- 小さな作業単位で計画し、AIが質問・提案し、人間が承認してから実装する。
- KPI目標値と収益モデルは初期仮説であり、実測やユーザー調査に基づいて更新する。
- 矛盾が生じたらCONTEXTに決定を記録し、関連文書を同期する。
