- React + TypeScript UI and Cloudflare Workers/Hono API

- Editable 3-minute script with version/status

- [ ] ローカル起動・型チェック・テストが通る

- [ ] 台本を生成または手入力して保存・再読込できる
- [ ] エラーと空状態が表示される
