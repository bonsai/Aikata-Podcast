# S2 — Recording and AI voice

- **Tier:** Tier 2 — Production workflow
- **Phase:** P2 — Recording
- **Tasks:** T06–T08
- **Goal:** 人間のマイク音声とAIホスト音声を別素材として収録・管理する。

## Deliverables

- Browser microphone capture with permission and retry handling
- TTS adapter for approved host lines
- Private R2 audio assets and D1 metadata
- Audio preview, replacement, and deletion

## Exit criteria

- [ ] 人間の録音を開始・停止・再生・やり直しできる
- [ ] AIホスト音声を生成・再生できる
- [ ] 2種類の音声が別々のassetとして保存される
- [ ] 削除後にファイルへアクセスできない
