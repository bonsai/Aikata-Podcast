# S3 — Edit and export

- **Tier:** Tier 2 — Production workflow
- **Phase:** P3 — Editing and export
- **Tasks:** T09–T11
- **Goal:** 音声トラックを整え、完成ファイルをダウンロードできるようにする。

## Deliverables

- Non-destructive track order, trim, and gain settings
- Mix preview
- Export job status and retry handling
- MP3 output when supported, otherwise WAV fallback

## Exit criteria

- [ ] 編集設定を保存・再読込できる
- [ ] プレビューが編集設定を反映する
- [ ] 完成音声をダウンロードできる
- [ ] 失敗理由が表示され、再試行できる
