## やることは7つ

1. **環境を用意**
   * Claude Pro以上
   * Claude Code
   * VS Code
   * GitHub
   * GitHub CLI gh
   * Node.js 22以上
   * Cloudflareアカウント

2. **Claude Codeで小さいアプリを1個作る**
   * 完成度は不要
   * 「言葉で頼む → 動かす → 触る → 修正を頼む」を体験

3. **自分の作りたいものを1個決める**
   * myapp を作る
   * CLAUDE.md に「このプロジェクトの約束」を書く
   * READMEに「何を作るか」を言語化

4. **AIに自分のアイデアを問い詰めさせる**
   * tsumete というエージェントスキルを作る
   * 曖昧なアイデアを仕様まで具体化
   * 必要なら CONTEXT.md に用語・決定事項を残す

5. **実装前にTASKS.mdを作る**
   * やることを小さく分解
   * MVPだけ残す
   * 「全部作る」ではなく「最小限動くもの」にする

6. **AIに実装させ、レビューして直す**
   * 1タスクずつ実装
   * 自分でブラウザを触って確認
   * AIレビュー
   * セキュリティレビュー
   * 修正
   * コミット

7. **公開する**
   * GitHubへpush
   * Cloudflareにデプロイ
   * 公開URLを作る

## 最終的に残ればOKなもの

```
myapp/
├── CLAUDE.md      ← AIへの約束
├── README.md      ← 何を作るか・仕様
├── TASKS.md       ← やること
├── CONTEXT.md     ← 用語・決定事項（必要なら）
├── .claude/
│   ├── skills/    ← 自分のAIへの作法
│   └── hooks/     ← 自動レビュー
└── アプリ本体
```

つまり、この教材の本質は、

**アイデア → AIに問い詰める → 仕様 → TASKS → AI実装 → 自分で触る → レビュー → 修正 → GitHub → 公開**

です。

MCP、Notion、Backlog、Gmail、拡張ミッションあたりは、最初は捨ててOKです。

特にぱぱさんの場合、すでにAIでかなり作っているので、教材を丸ごと消化するより、自分の既存プロジェクトを README + TASKS + CLAUDE.md に落として、この開発ループだけ移植するのが一番効きます。
